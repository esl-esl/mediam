# HSE Study Space

Полноценный адаптивный учебный планер в стилистике НИУ ВШЭ: дедлайны, динамические дисциплины, занятия, формулы оценивания, материалы, диплом и активности.

> Это независимый неофициальный учебный инструмент. Он не является продуктом НИУ ВШЭ.

## Что есть в приложении

- главный экран с расширенными дедлайнами, навигатором по четырём модулям и быстрыми ссылками на iStudy, SmartLMS, LMS, Smart Way, кампании выбора и SmartPro;
- автоматический график 2026/27: текущий модуль, учебный период, сессия или каникулы определяются по дате;
- список дедлайнов с фильтрами, приоритетами, подзадачами, статусами и календарём;
- единая страница предмета без вкладок: общая информация, формула, занятия, материалы, конспекты, дедлайны и оценки в сворачиваемых разделах;
- курсы могут идти в нескольких модулях; многомодульная дисциплина показывается в каждом соответствующем модуле;
- темы и занятия связаны многие-ко-многим; занятия отображаются карточками со статусами по дате и открываются в overlay-редакторе;
- типы занятий: лекция, семинар, НИС, контрольная, экзамен и практическое занятие;
- полный CRUD дисциплин трёх типов: обязательные, по выбору и МагоЛего;
- автоматический выбор из 20 иконок, буквенный вариант, цвета и шесть HSE-паттернов обложек;
- горизонтальная таблица оценивания с произвольными шкалами, форматами `+ / ± / −`, числом или текстом; групповые части формулы связываются с занятиями выбранного типа;
- загрузка или ссылка на ведомость с оценками;
- библиотека материалов: записи лекций, презентации, учебники, полезные ссылки и загружаемые файлы;
- конспекты в формате текста или ссылки с тегами и привязкой сразу к нескольким темам и занятиям;
- конструктор ВКР: название, переименовываемые и переставляемые текстовые блоки, ссылки и файлы;
- МагоЛего, практика, карьера, клубы и университетские события;
- отдельная компактная страница аналитики без расчёта средней оценки;
- светлая, тёмная и системная тема, HSE Sans/HSE Slab, мобильная навигация;
- автоматическое сохранение, резервная копия JSON и восстановление из файла.

Преподаватели намеренно не входят в модель или интерфейс приложения.

## Хранение данных

- **Cloudflare D1 / SQLite** — всё состояние пользователя: предметы, задачи, оценки, конспекты, диплом, активности и настройки.
- **Supabase Storage** — загруженные PDF, презентации, документы, таблицы, изображения и записи до 20 МБ. Bucket остаётся приватным, а секретный ключ используется только серверным API приложения.
- Данные разделяются по идентификатору авторизованного пользователя. При локальной разработке применяется локальный идентификатор.
- Изменения сохраняются автоматически через 700 мс после редактирования; индикатор синхронизации находится в верхней панели.

## Структура

```text
app/
  api/planner/route.ts      # чтение, автосохранение и сброс состояния D1
  api/files/route.ts        # загрузка, выдача и удаление файлов Supabase Storage
  subjects/[id]/page.tsx    # динамические страницы дисциплин
components/planner/         # весь интерфейс и редакторы
db/schema.ts                # схема D1
drizzle/                    # SQL-миграции
lib/planner-seed.ts         # стартовые данные и формулы
lib/planner-types.ts        # модель данных
worker/index.ts             # Cloudflare Worker bindings
lib/supabase-storage.ts     # приватное подключение к Supabase Storage
```

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Скопируйте `.env.example` в локальный файл окружения и укажите параметры Supabase. Откройте адрес, указанный Vite. Локальная D1 поднимается через Cloudflare Miniflare и сохраняется в каталоге `.wrangler/`.

## Supabase Storage

1. Создайте бесплатный проект Supabase и приватный bucket `hse-study-planner-files`.
2. В настройках проекта скопируйте Project URL и серверный Secret key.
3. В настройках Cloudflare Worker добавьте секреты `SUPABASE_URL`, `SUPABASE_SECRET_KEY` и обычную переменную `SUPABASE_STORAGE_BUCKET` со значением `hse-study-planner-files`.
4. Не добавляйте Secret key в GitHub и не используйте для него префикс `NEXT_PUBLIC_`.

R2 binding приложению больше не нужен. Метаданные файлов и их связи по-прежнему хранятся в D1; существующее имя столбца `r2_key` сохранено для совместимости и теперь содержит путь объекта Supabase.

Полная инструкция без терминала: [`SETUP_ONLINE.md`](SETUP_ONLINE.md). Для собственного Cloudflare Worker скопируйте `wrangler.example.jsonc` в `wrangler.jsonc` и укажите Database ID созданной D1.

## Основные маршруты

| `/settings` | профиль, темы, CRUD дисциплин и резервные копии |

## Настройка под себя

Первый запуск создаёт демонстрационное пространство на основе программы «Медиаменеджмент». Изменить его можно прямо в интерфейсе:

1. Откройте «Настройки → Дисциплины».
2. Добавьте обязательный курс, дисциплину по выбору или МагоЛего.
3. Выберите один или несколько модулей, кредиты, цвет, паттерн и ссылку на программу курса.
4. На странице предмета добавьте занятия, формулу оценивания, дедлайны и материалы.
5. Удаление предмета каскадно очищает связанные занятия, дедлайны, оценки, конспекты и файлы.
